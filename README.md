# SafeInstall

Android-қа арналған жергілікті APK ақпараттандырғыш-орнатқыш.

## Не істейді

- Қолданушы таңдаған APK-ні алдымен жеке cache-ке көшіреді.
- Қолданба атауын, package id, нұсқасын және файл көлемін көрсетеді.
- APK-нің SHA-256 хэшін және қолтаңба сертификатының SHA-256 дайджестін көрсетеді.
- Сұралған рұқсаттарды тізіп, сезімтал рұқсаттарды `⚠` белгісімен бөледі.
- Тек қолданушы батырманы басқаннан кейін Android-тың жүйелік орнатқышын ашады.
- APK-ні өзі орындамайды және автоматты түрде үнсіз орнатпайды.

## Маңызды шектеу

Рұқсаттар мен қолтаңбаны көрсету — қауіпсіздікті бағалауға көмектеседі, бірақ зиянды кодты 100% анықтау емес. Орнатпас бұрын APK-ні қайдан алғаныңды, қолтаңба хэшін және сұралған рұқсаттардың қолданба мақсатына сай екенін тексер.

## Құрастыру

Android Studio-да осы буманы ашып, Gradle Sync жаса. Қажет болса Android SDK 35 және JDK 17 орнат. Кейін `Build > Build Bundle(s) / APK(s) > Build APK(s)` таңда.

GitHub Actions workflow-ы да қосылған. `main`-ге push болған сайын жоба Ubuntu runner-де жиналып, `SafeInstall-debug-apk` атты artifact ретінде сақталады. Оны репозиторийдегі **Actions → Build SafeInstall APK → Artifacts** бөлімінен жүктеуге болады.

Жоба таза Java + Android Views арқылы жасалған, сондықтан қосымша сервер немесе аккаунт қажет емес.
